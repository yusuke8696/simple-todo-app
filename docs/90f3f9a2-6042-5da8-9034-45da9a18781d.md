# 要件定義

## 目的
個人用ToDo管理アプリの動作確認用プロトタイプを構築する。

## 対象範囲
- **プラットフォーム**: PCのWebブラウザ（Chrome・Edge）
- **技術スタック**: HTML, CSS, JavaScript (Vanilla)
- **データ永続化**: ブラウザの `localStorage`
- **実装ファイル**: `index.html` (単一ファイル構成)

## 要件一覧

### 1. タスクの追加
- **入力**: タスク名を入力するテキストフィールド
- **制約**: 
  - 空欄または空白だけの入力は追加不可
  - 文字数制限: 100文字以内
- **アクション**: 追加ボタンを押すとタスクがリストに追加される

### 2. タスク一覧表示
- 登録されたタスクをリスト形式で表示
- 各タスクにはチェックボックスと削除ボタンを配置

### 3. 完了状態の切り替え
- **未完了**: チェックボックス未選択、通常表示
- **完了**: チェックボックス選択、文字列を取り消し線（`<del>`）で表示
- 完了状態から未完了へ戻すことも可能

### 4. タスクの削除
- 削除ボタンを押すと確認ダイアログを表示
- ダイアログで「OK」を押すと削除、「キャンセル」またはダイアログ外をクリックすると元に戻す

### 5. データの保持
- ブラウザを閉じたり、ページを再読み込み（F5）したりしても、`localStorage` に保存されたデータは保持される

## 未決事項
- 本要件定義は動作確認用最小限の機能に限定されており、編集機能、期限管理、優先度、カテゴリ、リマインダー、ログイン、複数人共有は対象外である。
